# LoveBooks — Online Bookstore & Catalog

A responsive client-side web application for browsing, searching, rating, and purchasing books across categories including Fiction, Non-Fiction, Popular Reads, and Children's & Young Adult literature.

## Technologies & Features
- HTML5: Semantic structure, forms, SEO meta tags, and accessible image alt attributes.
- CSS3: Flexbox, CSS Grid, Bootstrap 5, responsive media queries, and keyframe animations.
- JavaScript & jQuery: Dynamic DOM rendering (`map`, `filter`, `reduce`), `localStorage` shopping cart, form validation, and interactive star ratings.
